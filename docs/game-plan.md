# 06 — Game Plan · Gilfforever
**MVP, prazo, equipe, risco e monetização**

## 1. Escopo do MVP (o mínimo que já entrega e cobra)
**Entra:**
- Conta + casal + convite do parceiro
- Linha do tempo (foto/vídeo/áudio/texto)
- Cápsula do tempo (selar + abrir por push)
- Datas importantes + lembretes
- Assinatura com trial de 7 dias (RevenueCat/Stripe)
- Exportação de dados

**Fica pra fase 2:**
- Retrospectiva anual automática
- Álbum físico impresso (upsell)
- Modo cofre / privacidade avançada
- Offline-first

## 2. Fases e prazo (realista pra time enxuto)
| Fase | Entrega | Prazo estimado |
|------|---------|----------------|
| 0 — Validação | Landing + funil rodando, captar interessados/beta | 1–2 semanas |
| 1 — MVP | App Expo + backend + assinatura + cápsula funcionando | 6–10 semanas |
| 2 — Lançamento | Publicar nas lojas, ligar funil→app, primeiros pagantes | +2 semanas |
| 3 — Crescimento | Retrospectiva, upsells, otimização de funil/retenção | contínuo |

## 3. Equipe mínima
- 1 dev full-stack (Expo + backend) — pode ser você com os agentes AIOX.
- 1 designer (ou usar o Design System já definido + templates).
- Você: produto, funil, tráfego, conteúdo.
> Dá pra rodar o MVP solo com apoio dos agentes; escalar time só depois de validar pagamento.

## 4. Monetização
- **Assinatura mensal e anual**, trial de 7 dias.
- Preço-âncora a testar (ex.: mensal R$ 19–29, anual com ~40% de desconto).
- 1 assinatura por casal (2 usuários) → menor fricção, mesmo LTV.
- Upsells futuros: álbum impresso, armazenamento extra, temas.
- **North Star de receita:** conversão trial→pago e churn < 5%/mês.

## 5. Riscos e mitigação
| Risco | Mitigação |
|-------|-----------|
| Churn depois da emoção inicial | Cápsulas futuras + retrospectiva + lembretes seguram a recorrência |
| Diferenciação vs. TimeHut/concorrentes | Posicionamento 100% casal + cápsula como marca |
| CAC alto | Funil conversacional barato + viralização (parceiro convidado = 2º usuário grátis) |
| Custo de mídia | Compressão + R2 + limites por plano |
| Confiança (dados íntimos) | Privacidade forte + exportação garantida + comunicação clara |

## 6. Go-to-market
1. Rodar o **funil conversacional** (../marketing/funil-gilfforever.md) como aquisição principal.
2. Nichos de entrada: aniversário de namoro, "presente que dura", pedido de casamento.
3. Coletar depoimentos REAIS desde o beta (prova social honesta pro funil).
4. Otimizar trial→pago antes de escalar tráfego.

## 7. Próximo passo concreto
Abrir o VS Code e iniciar a **Fase 0**: subir a landing + funil e ligar o formulário de captação (nome, parceiro, data) que já alimenta o onboarding do app. Com validação de interesse, parte pro MVP (Fase 1).
